Contexto

Sobre o projeto

Este dashboard foi criado como parte prática dos treinamentos de Power BI da Hashtag, com o objetivo de transformar uma base de vendas fictícia da "Hashtag Eletro" em um painel de indicadores claro e navegável.

O foco esteve em todo o fluxo de uma análise real: extração e limpeza dos dados no Power Query, modelagem das tabelas, criação de métricas em DAX e construção de uma experiência visual que facilite a leitura por quem toma decisão.

Nota sobre os dados: os dados utilizados neste projeto são fictícios e fazem parte do material de treinamento da Hashtag Treinamentos, usados aqui exclusivamente para fins de prática e aprendizado.

Metodologia e ferramentas

O desenvolvimento seguiu o fluxo padrão de um projeto de Power BI: importação e tratamento dos dados no Power Query, modelagem em estrela, criação de medidas em DAX e, por fim, o design das páginas do relatório, publicado via Microsoft Fabric.
